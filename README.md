# matthewholman.github.io

Personal website of Matthew J. Holman. Plain HTML and CSS, served by GitHub Pages.

- Edit the page bodies in `src/`, then run `python tools/build.py`.
- Refresh the publication list from NASA ADS with `python tools/update_pubs.py` (needs an ADS token).
- `cv/holman_cv_web.tex` builds `cv.pdf`.
